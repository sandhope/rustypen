## 项目简介

Rustype 是一款轻量、高性能的 Markdown 桌面编辑器。核心基于 Rust + Tauri，前端使用 React，启动快、体积小，在 Windows、macOS 和 Linux 上均可原生运行。

## 核心特性

- ⚡ **快速轻量** — Rust 驱动的内核，体积小巧、秒开秒用
- 📝 **Markdown 优先** — 专注写作体验，支持实时渲染
- 🌙 **深浅色模式** — 自动跟随系统外观
- 🖥️ **跨平台** — 一套代码同时支持 Windows、macOS 和 Linux
