## Overview

ContextMenuManager helps you take control of the Windows right-click context menu — view, enable and disable menu entries so your context menu stays clean and fast.

## Features

- 🧹 **Clean up clutter** — disable context menu entries you never use
- 🔍 **Full visibility** — see which programs registered which entries
- 🖥️ **Windows native** — built with C# for Windows
