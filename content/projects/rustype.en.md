## Overview

Rustype is a lightweight, high-performance Markdown desktop editor. Powered by a Rust + Tauri core with a React front end, it starts fast, stays small, and runs natively on Windows, macOS and Linux.

## Features

- ⚡ **Fast and lightweight** — Rust-powered core with a tiny footprint and instant startup
- 📝 **Markdown first** — a focused writing experience with live rendering
- 🌙 **Dark & light mode** — follows your system appearance
- 🖥️ **Cross-platform** — Windows, macOS and Linux from a single codebase
