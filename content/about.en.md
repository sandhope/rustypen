## Hi, I'm sandhope 👋

I build open source software — desktop apps and developer tools for Windows, macOS, iOS and Linux. This site is the home of all my projects: browse the [project list](/projects/), check out screenshots and features, and grab the latest releases.

## About this site

This site itself is open source and intentionally boring in the best way:

- **Zero dependency** — no npm, no `node_modules`, no framework churn. Just [Hugo](https://gohugo.io/) and hand-written HTML/CSS.
- **Markdown driven** — every project page is a single markdown file.
- **Source code** — [github.com/sandhope/rustypen](https://github.com/sandhope/rustypen)

## Get in touch

Found a bug or have an idea? Open an issue on the corresponding [GitHub repository](https://github.com/sandhope) — that's the fastest way to reach me.
